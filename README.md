# PAER evaluation harness

Reproducible harness for **"Where to Enforce Authorization in Enterprise Retrieval-Augmented Generation: The PAER Reference Architecture and a Reproducible Evaluation"**.

Every number, table, and figure in the paper is regenerated by the scripts in this directory from the stated seeds.

## Contents

| Path | Purpose |
|---|---|
| `paer/common.py` | Policy model (tenant + clearance, analyst/manager), the four enforcement designs (D0 unfiltered, D1 top-k post-filter, D2 over-fetch post-filter, D3 pre-filter), metrics, Mann-Whitney AUC |
| `paer/synthetic.py` | Experiment A: mirrored synthetic benchmark (270 docs, 3 tenants, lexical overlap, k = 2), self-consistency checks E1/E2/E4/E5, timing |
| `paer/reuters.py` | Experiment B and C: Reuters-21578 loader, policy assignment, headline/sentence query generators, BM25 and dense (WordLlama + FAISS) retrievers, evaluation, result-count existence oracle |
| `paer/revocation.py` | Experiment D: revocation lag replay (Poisson queries and revocations; E2 reconciliation interval × E4 re-check mode) |
| `paer/latency.py` | Experiment E: enforcement cost and effective recall on FAISS flat, FAISS HNSW, partitioned, and Qdrant (local mode) indexes |
| `run_reuters.py` | Driver for B (main, sentence, sweeps, seeds) and C (oracle grid) |
| `run_revocation.py` | Driver for D |
| `run_latency.py` | Driver for E |
| `make_figures.py` | Generates all manuscript figures from `results/*.json` |
| `run_all.py` / `run_all.sh` | Runs everything in order (cross-platform / bash) |
| `get_data.py` | Downloads and unpacks Reuters-21578 |

## Requirements

Python 3.11 or newer. Install the dependencies from the package root:

```
pip install -r requirements.txt
```

(numpy, scipy, faiss-cpu, qdrant-client, wordllama, matplotlib, python-docx). Tested with numpy 2.5, scipy 1.16, faiss-cpu 1.15.1, qdrant-client 1.20.0, wordllama 0.4.0.post1, matplotlib 3.10, python-docx 1.1.

**WordLlama offline note.** The 256-d `l2_supercat` weights and tokenizer ship inside the wheel. Version 0.4.0 looks for the tokenizer under `wordllama/tokenizer/` while the wheel installs it under `wordllama/tokenizers/`; `paer/reuters.py` detects this and creates the missing alias automatically, so no manual step is needed. If that fails and the machine has network access, the library downloads the one file it needs.

## Data

Reuters-21578 (ModApte split, as distributed with NLTK). From the package root:

```
python harness/get_data.py
```

This downloads the 6 MB archive from the nltk_data GitHub mirror and unpacks it to `data/reuters/`.

## Run

From the package root, cross-platform:

```
python harness/run_all.py
```

or, on macOS/Linux, `bash harness/run_all.sh`. Approximate wall-clock on a 2-core VM: Experiment A under 1 min; B and C about 10 min; D about 1 min; E about 60 min (the Qdrant in-memory client dominates); figures under 1 min. A modern laptop is faster. `python harness/run_all.py --quick` halves the Reuters workload for a smoke test; do not use its output for the paper.

## Rebuild the manuscript

From the package root:

```
python manuscript/build_manuscript.py
```

This writes `PAER_JCP_manuscript.docx` into the package root, with every number read from `results/*.json` and every figure from `figures/`.

## Output

`results/expA_synthetic.json`, `results/expB_main.json`, `results/expB_sentence.json`, `results/expB_sweeps.json`, `results/expB_seeds.json`, `results/expC_oracle.json`, `results/expD_revocation.json`, `results/expE_latency.json`, and `figures/fig1..fig8.png`.

## Seeds

All experiments use seed 20261014 (plus fixed offsets for sub-generators). Experiment B's seed-robustness run uses 20261014 to 20261018.
